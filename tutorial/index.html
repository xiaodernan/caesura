CAESURA · TUTORIAL

止音纪元 · 入门小册子

把每个按键都敲响一次——只需要刚刚好这几分钟

Start a fresh run Console mesh Full guide
01
开弦
第一次进入游戏，标题会出五张出身卡。挑一个你喜欢的、看一眼它给的武器和被动，按下 ← → 选好了按 Enter 确定——你的出身因此被钉死，再也换不了。
IS ELASTIC · 出身不只是数值，是一段人生
02
横拖
WASD 在横拖中移动。左键 鼠标左键 轻击，右键 鼠标右键 重击。Shift 冲刺，Space 跳跃，Ctrl 偏闪——三分攻击，七分缓步。
SLOW IS FAST · 慢是常态，急才是风险
03
弹反
F 格挡，G 弹反。弹反右击一声之后你的节奏不串不抢，对面会踉跄。形形色色的 BOSS 都先做好这件事，再去打它。
无轻不重 · 后发先至
04
锁定
靠近对手时按 Q 锁定，Q 多按几次切锁。锁头之后你的视角会跟着它跑，打起来稳定得多。打完再切回 Q 放掉，不要一直锁。
锁定半屏，右侧弱点显示：火眼金睛看一眼
05
音色相生
武器的每一下都在唱（轻微的声音跟着音符走）。FlewV 可以停下来听一听——「声纹观察」——按下去你的女主角会闭眼停 3 秒，世界一静，所有人都暴露调性。「天照」技能就是这么来的。
V · 听世界 · 三秒后再动，很多事会变
06
耳鸣
听到魔物呻吟、铃钟颤振、脚下石屑纷飞？那是它听到你了。声音 = 你在哪，声音 = 敌在哪。在真正的回响 Hall，沉默是唯一安全的语言。
注意多余回响——多一步，多一记耳边光
07
寄存
任何时候都可以按 Esc 暂停。菜单里只有三件事：继续 / 调出锻造 / 存档+退出。新手最好的朋友 Esc 不要藏起来，它是你最安静的朋友。
不需要记住敌方位置——只要你记得 Esc 在哪
一句给玩家的备忘
止音纪元不送你一把斩钉截铁的胜利——它送你一口铃，一个耳鸣，和一笔账。好好吹一吹那一口铃，玩家不用去看什么百科。
