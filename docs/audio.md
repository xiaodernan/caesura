## 0. 资产策略声明（需求 §51）

本项目**没有任何外部音乐/音效素材**。全部音频 = WebAudio API 实时程序合成（OscillatorNode / BiquadFilter / ConvolverNode / 自定义 ScriptWorklet 粒子合成）。无版权风险，也无录音棚级质感——我们承诺的是**设计与系统完备度**（调性、节拍、混音规则），不是拟真采样。所有合成参数在下文给到参数级，可直接实现；状态标注：**Placeholder→Implemented 路径**记录于 KNOWN_ISSUES.md。

总线约定（全局唯一）：`MASTER → { MUSIC, AMB, SFX, UI, DIEGETIC }`，全部经分析器节点输出 loudness 统计供 §8 混音规则使用。

## 1. 调性系统（Tonality System）

世界观即音乐：调性 = 世界的健康度。系统由 `HarmonyDirector` 单例管理。

### 1.1 基础规则表

| 状态 | 调性 | 说明 |
|---|---|---|
| 探索（默认全局） | **C Dorian**（C-D-Eb-F-G-A-Bb） | 小调底色但升 6 级 A 带来"行进中的希望感"，全游戏主题调 |
| 战斗遭遇 | **C Aeolian（同主音自然小调）**：A→Ab | 主音不变、色彩变暗——玩家"仍在同一个世界，但歌走调了"；转换必须落在小节线 |
| 精英/Boss 战 | 各区 Boss 专属调（见 §6） | 转入时用共同音 C 做 pivot chord |
| 危险/失谐 Corruption 高 | C Dorian ♭2（Db 经过音渗入） | 只在和声层加半音脏音，旋律层保持干净=不安但可读 |
| 休止状态（主角能力） | 全频低通（§5）+ 和声层停拍 | 音乐"被按停"，只剩低频残振 |
| Hub 安全区 | F Lydian（C 系统的下属调，升 4 级） | 唯一的"明亮解决"，回家=调性呼吸 |

### 1.2 区域主音分配（ambience 与世界音乐层）

| 区域 | 主音 | 音程色彩 | 与全局 C 的关系 |
|---|---|---|---|
| 休垒 | F | Lydian 暖 | 下属——归属 |
| 雾语林 | C | Dorian 本调 | 主——世界的默认 |
| 钟坠院 | G | Mixolydian（钟的泛音列暗示） | 属——悬而未决 |
| 无耳深窖 | D | Phrygian（♭2 压迫） | 远关系——异化 |
| 破拍营地 | Bb | Aeolian 军乐化 | 关系大调的暗面 |
| 沉唱堂 | Ab | 全音阶碎片 | 三全音代理——"仪式失败的音" |
| 未竟厅 | C→无调（P2 起十二音音簇） | 调性崩塌=恩希尔"无拍" | 终局：主题调被摧毁再被玩家夺回 |

- 转场规则：跨区 8 小节 crossfade，先淡出旧区节奏层，再淡合声层，旋律层最后（保持连贯错觉）。
- **"停"有两种，必须能听出差别（Phase 5-C2b 落进 `src/audio/music.ts`）**：`audio.music.encounter { start:false }` = 脱战 ⇒ 战斗层 4s 淡出；带 `cut:true` = Boss 胜利序列 ⇒ **立刻**把战斗层增益归零并取消所有已排程的斜坡。IP §6 的"音乐停=世界屏息"要的是后一种——淡出听不出"停"这个字。**氛围 drone 两种都不掐**：屏息是世界屏住呼吸，不是关机。已知代价：若那一刻还有小怪在交战，`CombatManager` 的 30-tick 音乐轮询会把战斗层带回来（如实登记，不做静默特判）。
- 主题动机：**BACH 式四音动机不做**（避现实作曲家关联）。原创动机 `R-1`：C–Eb–G–Bb（遗响四音，上行琶音=世界之歌残片），出现在所有正向事件（拾取/净化/升级）；`R-1` 的倒影（下行）= 褪色/失谐事件。全游戏一切旋律写作只允许派生自 R-1 及其四种变形（倒影/逆行/扩张/压缩）——这是"世界是一首歌"的音乐宪法。

## 2. 节拍网格与战斗对齐（与 combat.md 的接口契约）

**原则：BPM 是敌人攻击网格的来源**（不是反过来）。战斗是合奏，敌人攻击 = 节拍上的音符。

### 2.1 数据流

```
combat.md 敌人数据表                audio: BeatClock（权威时钟）
EnemyData.bpm: 90          ──注册──▶ BeatClock.setTempo(zone/encounter)
EnemyData.attacks[i]:                       ├─ onBeat(n) 事件广播
  { beatRef: 2.0,           ◀──查询────     ├─ getPhase(): 0..1 拍内相位
    windupBeats: 2.0,                        └─ getBar(): 小节序号
    hitAt: "beat+0" }
```

- 攻击三窗口全部以**拍**为单位定义，由 BeatClock 换算为 ms：`startup = windupBeats × 60000/bpm`。动画、hitbox、telegraph 音效、音乐重音四方共用同一相位源——弹反窗口在重拍上（奥斯塔拉设计根基）。
- 音乐侧保证：战斗 BGM 的重拍（bar 内 beat 1）与敌人主攻击的平均落拍对齐（编排时按 enemy beatRef 写）。
- 战斗开始：`EncounterTrigger → BeatClock.snapToNextBar()（≤2 拍内进战斗曲）`；战斗结束：胜利乐句在最后一个敌人死亡的**帧数对齐拍点**触发（延迟 ≤ 1 拍，不可提前）。
  - 实现口径（KI-068，2026-09-27）：这一条落成了**只读查询** `RhythmClock.barEntry(maxWaitBeats = 2)`，而不是字面上那句"把钟 snap 到小节头"——移钟会连带挪走场上所有在飞招式的 hit-frame 量化（就是上面那条共用相位源的前提），为音乐的落点去动玩法的拍，代价方向反了。查询回答两件事：`waitSec`（还要等多久）与 `beatIndex`（落点是第几拍），由 `CombatManager` 在遭遇事件里交给音乐层，音乐层据此定第一拍的时刻与鼓点身份。**两支**：小节头在 2 拍预算内 ⇒ 等小节头；够不着 ⇒ 夹到下一拍点并**照它的真拍号演**（4/4 里有一半时刻离小节头 >2 拍，「必踩小节头」与「≤2 拍」不可能同时恒成立，夹子是把这条承诺兑现成可执行的那一步）。
- 动态强度（vertical layering）：层 L1 节奏底/L2 和声/L3 对位旋律/L4 铜管替代物（合成管风琴吹管层），按 `threat = Σ存活敌威胁分/初始` 分层进出，进出只允许在小节边界。

### 2.2 各区战斗 BPM 表

| 场景 | BPM | 拍号 | 说明 |
|---|---|---|---|
| 杂兵遭遇（野外） | 92 | 4/4 | 走路感，允许玩家闪避在 2/4 拍 |
| 破拍营地大战 | 104 | 4/4 | 军乐行进 |

## 3. 程序化合成规格（参数级）

### 3.1 钟（Bell）——世界第一音色：`SYN_BELL`

FM 加性混合钟（奥斯塔拉/休垒圣钟/拾取音共用）：

| 参数 | 值 |
|---|---|
| 架构 | 6 operator FM 载波 + 3 条加性失谐正弦 |
| 泛音比（非谐比，钟的物理） | 1 : 2.0 : 2.4 : 3.0 : 4.5 : 5.73（拒绝弦乐整数比=一听即钟） |
| 基频 | 大钟 C2=65.4Hz 起，按 `ratio^1.08` 半音化排布（钟组=音阶） |
| 包络 | attack 2ms，decay 按泛音序号 `t_i = 6s / i^1.3`（高泛音先死=金属感） |
| 敲击瞬态 | 带通噪声（中心 2.2kHz，Q=1.4，30ms）+ 次声锤击 sine 55Hz→28Hz pitch drop 40ms |
| 调制 | 每次随机 detune ±8 cents、部分激发随机（模拟钟模态），禁止两敲完全相同 |
| 混响 | 卷积（程序生成 IR：噪声×指数衰减 2.2s，金属染色 = 1.8–3.2kHz 峰） |

### 3.2 管风琴（Organ）——恩希尔身份：`SYN_ORGAN`

| 参数 | 值 |
|---|---|
| 音栓组（drawbar，Hammond 式命名但原创比例） | 16'正弦 +8'正弦 +5 1/3'（三方泛音）+2' +1 1/3' 尖音栓（可选） |
| 各栓电平 | 8' 主 1.0；16' 0.45；5 1/3' 0.4；2' 0.25；Mixtur 0.12 |
| attack | 35–60ms 随机（风路惯性）；release 120ms 后尾风 0.5s 低电平嘶声 |
| 关键噪声 | key-on 气流瞬态：800Hz 带通噪声 25ms，电平随力度 |
| 微失谐 | 每管 ±3–6 cents 慢漂移（LFO 0.1Hz）——活的风箱感 |
| 风箱呼吸 | 全局音量 LFO 0.25Hz ±4%（恩希尔 P2 放大此 LFO = "它在喘"） |
| 和弦上限 | 8 声部；音簇（tone cluster）专用奏法：白键相邻 5 音同按 + 弯音 -20 cents 慢斜=失谐威压 |

### 3.3 鼓（Drums）——战斗节奏底：`SYN_DRUM_*`

| 音色 | 合成 |
|---|---|
| 大鼓（驼鼓/定音） | sine 160→48Hz 指数滑 90ms + 拍面噪声 300Hz 低通 15ms；Q 包络 8→2 |
| 军鼓/边击 | 200Hz 膜正弦 + 1–2kHz 高通噪声 80ms 衰减（响弦替代=金属噪声梳） |
| 节拍木（嘈壳） | 680Hz+1020Hz 双正弦 18ms 脆衰减 |
| 镲/锣（漂调者） | 12 条 300–6000Hz 非谐正弦 + 白噪，1.2s 衰减，用于 accent 不用于拍点 |
| 群鼓滚奏 | 8–16 个微偏移大鼓（±12ms）并发 = 军队鼓点，无需采样 |

### 3.4 失真人声替代品（Choir Substitute）：`SYN_VOICECLUSTER`

不用录音人声、不用 VTS；用共振峰合成器模拟"三百歌者被叠进管风琴"：

| 参数 | 值 |
|---|---|
| 源 | 锯齿波（-12dB/oct 预低通防混叠）per 声部 |
| 共振峰 | 3 级并行 bandpass：F1 700Hz/Q9、F2 1220Hz/Q11、F3 2600Hz/Q13，元音在 /a/–/o/ 间以 0.08Hz LFO 缓移 |
| 声部 | 8–16 声部，同音高群 ±15 cents 散布 + 各自 4.8–5.6Hz 颤音（相位随机）=合唱感 |
| 失真 | 波形折叠（wavefolder ×3）随"失谐度"参数 0→1；恩希尔 P1 用 0.25，P2 用 0.55，Final 0.85=圣咏变嘶吼 |
| 无词吟唱 | 只用 R-1 动机音高；禁用任何可辨语义词（避免真实语言版权/文化问题） |
| 人声"哀鸣"点缀 | 单声部 glissando +2 半音再落回，600ms——用于沉唱堂环境事件 |

## 4. 区域 Ambience 分层（每区 4 层，AMB 总线）

层模型：`L1 Drone（持续根音）/ L2 Texture（颗粒声纹）/ L3 Motion（风/水/链等物理动源）/ L4 Event（稀疏叙事事件，30–120s 随机）`。各区参数：

| 区域 | L1 | L2 | L3 | L4 事件样例 |
|---|---|---|---|---|
| 休垒 | F2 大提琴式锯齿暖 drone -24dB | 炉火噼啪颗粒、铁砧余震 | 风掠过肋骨穹顶的哨音（和弦化：F Lydian #4 轻啸） | 远处圣钟单敲；盐歌唱歌时 L2/L4 整体让位她的旋律线（Hub 音乐层随 NPC 状态变化） |
| 雾语林 | C2 drone + 飘忽五度 | **录放残片**：倒放/变速的铃与吟唱碎片（granular，源=本项目合成音自采样） | 湿叶滴水、雾的白噪压感 | 百年前的对话残句（不可懂人声形态）、金色浮尘的高频铃点 |
| 钟坠院 | G2 + 金属嗡鸣 | 钟体受风低频哼鸣（SYN_BELL 超低电平长激） | 断链摆动吱呀、落日风 | 无风自敲（预告 Boss 节奏语言）；碎石落入钟腔回响 |
| 无耳深窖 | **D2 之下：40Hz 次声 drone（体感>听感）** | 矿光"嗡"（病白=高频细啸 6kHz -40dB 若隐若现） | 水滴稀疏化——**越深声音间隔越长**（-1s/100m 直至几乎无事件） | 玩家静止 20s+ 后：一声不属于任何来源的"耳语被剪断"锐声（万籁预告，只此一次/存档） |
| 破拍营地 | Bb2 进行鼓底（48bpm 半速军鼓，鬼拍） | 旗杆绳结、甲片碰撞 | 巡逻脚步（死军阵：永远整齐得不对） | 节拍灯"啪-啪"与鼓点错位 ±60ms（"破拍"的听觉直译） |
| 沉唱堂 | Ab2 管风琴栓 16' 独音（空堂感） | 水面涟漪颗粒 | 持续极轻的水声 | 唱诗席倒悬处偶发 1 声部走音独唱，随即被水声淹没 |
| 未竟厅 | 无 drone——风箱底噪 | 音管漏气嘶声、灰尘级高频 | 建筑级金属应力呻吟 | P1 内每 45s 一次"排练音阶"从琴体深处传来又中断 |

- 3D 化：所有 L2–L4 为 PannerNode 声源实体（真位置），L1 为 2D 铺底。HRTF 开启。
- 与视觉接口：L4 事件触发时对应区域可产生极光带微亮反馈（art-direction.md §10）。

## 5. 主角"休止"状态听感设计（全频低通，本作签名音效）

**听感目标：世界安静下来，只剩你自己的身体。** 触发：完美弹反后蓄满的"共振过载"消耗 / 叙事强制节点。

| 阶段 | 时间线 | DSP |
|---|---|---|
| 入 | 0→250ms | MASTER 前置 2-pole LP：22kHz→140Hz 指数斜降；同步 MUSIC/AMB 音量 -12dB；混响 wet 0.45→0.1、tail 0.3s（空间被"抽干"） |
| 持 | 状态内 | 只透三个元素：**心跳**（SYN_DRUM 大鼓变体 46bpm，40–80Hz）、**骨传导低音**（38Hz sine + 玩家动作产生的极窄带材质音——脚步只有 60–120Hz 闷响）、**弹反提示**（敌人攻击前摇的"振动轮廓"以 3kHz 窄带啸叫出现在声像方向=听声辨位玩法化） |
| 出 | 180ms | LP 22kHz 回扫 + 全总线一个上行 R-1 琶音"换气"——恢复感来自频响扩张本身 |
| 侧链 | 全程 | 休止内敌人音效 -12dB、Boss 音乐 -18dB：**世界被压低，玩家被凸显**——这是"休止特權"的声音表达 |

- 敌人（喧堕者）在休止内可见但"失声"——它们的 telegraph 音高上扬被替换为音高**下沉**闷击：读条难度略升，换来更强的掌控幻想（设计权衡已定，不改）。

## 6. Boss 音乐身份（需求 §40：音乐=Boss 身份）

### 6.1 悬钟骑士·奥斯塔拉 —— `MUS_OSTLARA`：**纯打击 + 钟**

- 编制：定音群鼓 + SYN_BELL 钟组 + 木拍；**零和声层零旋律**——它是"节拍本身"。
- 100bpm 3/4，结构即机制：
  - P1 钟壳期：每 4 小节一次钟敲（=它撞钟自震的无敌循环外显），玩家听到的敲钟声=场地机关提示音。
  - P2 双剑狂板：鼓点织体加密（四分→八分），但重拍弹反窗口永远在第 1 拍——音乐即教学。
  - P3 拔钟抡砸：每 8 小节一次全钟齐鸣=大招；尾奏：钟的泛音一个个死去（各泛音 decay 拉长 2 倍逐个静音）再再是胜利。
- 失败代价听觉化：玩家体力耗尽时鼓组去掉底鼓——"你的节拍断了"。

### 6.2 无拍长·恩希尔 —— `MUS_HERSIL`：**管风琴 + 人声簇**

- P1：**无小节线**。音乐随玩家血量与距离"即兴"（程序化选择动机 R-1 的碎片，速度 rubato ±20%）——玩家无法从音乐预判攻击，只能读动作。人声簇是三百歌者：偶发 2–3 声部"抢先"唱出完整圣咏又瞬间被折叠失真吞掉（姐姐声音的暗示：唯一女声部 F4 固定音高，比人声簇亮 1dB）。
- 60% 转阶段：管风琴全栓齐鸣音簇 8s → 竞技场塌陷 → 环境伤害乐句化："续章残篇"旋律（可背诵的 8 小节圣咏，每次演奏循环 = 一次环境伤害波）——**玩家对这段音乐熟悉得可怕，就是设计目的**。
- P2 夺拍机制：BGM 与 gameplay 网格**故意错拍**（每 4 小节 -25ms 累进漂移），玩家每次精准弹反"休止"它 → 音乐瞬间吸附回网格 2 小节作为奖励——"夺回节拍"不是比喻，是玩家用操作演奏出来的。
- Finale：风箱 LFO 加大、音管啸叫（正反馈音高失控设计到 -6dB 封顶）、人声簇失真 0.85，处决每完成一次掐灭一个声部——玩家亲手让歌声安静。胜利：剩余声部归于单声部女声一个长音渐弱→心跳（进入 §5 休止的听觉世界=叙事回响）。

### 6.3 万籁 the Myriad —— `MUS_MYRIAD`：**没有音乐**

- 本 Boss 无配乐。整场只有 diegetic 声：肉质耳兽的摩擦、音刺的远处嗡鸣、**玩家自己发出的一切声音**。
- 用"没有音乐"做配乐 = 把 §39"音频第一等公民"反过来用：玩家第一次意识到"声音是危险"（机制：攻击声吸引它，潜行/投掷音色晶声东击西）。
- 实现规则：战斗全程 MUSIC 总线音量 0；玩家脚步声量随奔跑/闪避实时映射 -30→0dB（UI 上以声纹环可视化，接 ui-ux.md）；唯一"类音乐"元素：它靠近时 40Hz 次声渐强——听到之前先感到。
- 击杀瞬间：全静默 1.2s（总线 gate 0）→ 拾取「无鸣」时一声极轻的高泛音铃（4.5 分音，-24dB）——奖励是"安静"。

## 7. SFX 类别表（SFX 总线，程序合成）

### 7.1 脚步（材质 × 速度 矩阵）

`SFX_FOOT_{材质}_{walk|run|spin}`，材质集：stone / bone（休垒骨腔，特有"空腔噗声"低频）/ wood-litter（雾语林落叶湿声）/ metal-bell（钟坠院，带微泛音尾）/ water-shallow / gravel-camp / crystal-mine（深窖，高频丁零）。参数模板：宽带噪声 burst（25–60ms）+ 材质共振带（stone 180Hz Q2 / bone 90Hz Q1.4 衰减 120ms / metal 2.4kHz Q8 / crystal 3.6+5.2kHz 双峰 180ms）+ 步幅力度映射音量 -18→-6dB、随速度提密度（walk 2.2Hz / run 3.1Hz）。

### 7.2 武器挥动（按武器 6 类）

| 武器 | 特征合成 |
|---|---|
| 调律剑 | 纯净"咻"：带通噪声 800→2400Hz 扫频 120ms + 轻音叉尾振（命中后 2.8kHz 铃） |
| 强音大剑 | 低频撕裂：噪声 200→600Hz 250ms + 和弦蓄力期 3 音鸣响 |
| 引针枪 | 短促"噗嗤"气流，投掷后弦鸣 |
| 泛音弓 | 拉弦摩擦（锯齿+噪声梳）拉满时泛音分叉=上行琶音音点数=目标数（声音即机制） |
| 音叉杖 | 演奏型：技能=和弦发声，全类唯一以音高表达威力的武器 |
| 无鸣 | **无声**：只有 20ms 的 -36dB 高频耳光感——背击的"寂静"是它的音色 |

### 7.3 Impact 集

| 事件 | 设计 |
|---|---|
| 轻击命中 | 闷拍 140Hz 30ms + 材质层（甲=金属梳/肉=低频啪） |
| 重击命中 | 上者 + SYN_DRUM 军鼓 + 0.1s 延迟回声一次（"回响"状态呼应） |
| 弹反成功 | 全游戏最亮音色：钟 4.5 泛音短击 + 金白闪同步 ≤10ms——正反馈音画锁死 |
| 完美格挡 | 低频"铛"+盾面嗡鸣 400ms |
| 破处决 | 音叉巨剑"消音"：一切声音 80ms 内塌向 100Hz 低通——处决是"让声音死"（**已实现**：`AudioEngine` 的总线低通 + `execute_rest` 专属音色；开关只有一格事件，长度跟着处决演出走，实机读回 132 tick 与 `execution.durationTicks` 相同。同一条里的"休止内敌人音效 −12dB / Boss 音乐 −18dB"侧链**未做**，见 KI-003 与 §5） |
| 玩家受击 | 中低频钝响 + 受击方向 Panner（闭眼可辨向） |
| UI（见 §7.4）/ 拾取 | R-1 上行四音各 55ms 快琶音——货币/升级/拾取同动机（正向=R-1，负向=倒影） |

### 7.4 UI 音（UI 总线，全走 R-1 动机）

## 8. 混音优先级与 Ducking（MASTER 响度目标 -14 LUFS，峰值 -1dBTP）

### 8.1 优先级表（0 最高；同层内按距离衰减）

| 优先级 | 元素 | 目标电平 |
|---|---|---|
| 0 | 弹反/处决/休止出入音效 | -6dB（全混音最响席位） |
| 1 | Boss 音乐关键重拍、玩家受击 | -9dB |
| 2 | 敌人 telegraph 上扬音、UI 确认 | -12dB |
| 3 | 常规武器命中 | -14dB |
| 4 | MUSIC 持续层 | -18dB |
| 5 | AMB L2–L4 事件 | -22dB |
| 6 | AMB L1 drone | -28dB |

### 8.2 Ducking 规则表（侧链全为程序 sidechain：源→检波→增益目标 dB）

| 触发源 | 被压对象 | 量/时间 |
|---|---|---|
| 休止状态 | 除心跳/骨传导外全部 | -12→-18dB，250ms 入 180ms 出 |
| 弹反成功 | MUSIC+AMB | -6dB / 300ms（让"那一响"称王） |
| Boss 大招 telegraph | AMB 全层 | -8dB / 1.5s（危险独占听觉空间） |
| UI 确认音（菜单中） | MUSIC -3dB / AMB -6dB | 400ms |
| 玩家靠近声源（L3/L4） | 同类远处事件 | 同型事件并发 ≤2（防颗粒轰炸） |
| 万籁战 | MUSIC 总线 | 0（永久静音，见 §6.3） |

### 8.3 动态与防疲劳

- 探索段 MUSIC 与 AMB 常驻差 ≤ 6dB；战斗峰值比探索峰值高 8–10dB——落差即紧张感。
- 长连击命中音音高逐次 +2 半音循环（8 次一循环）防"机关枪效应"。
- 响度战争不适用：宁可在混音里给打击留 headroom，不做主压限"糊墙"。
