## 0. 战斗设计支柱

| 支柱 | 判据 |
|---|---|
| Responsive 响应 | 输入→动画 ≤100ms；输入缓冲 200ms；取消规则全表化（§3.2） |
| Readable 可读 | 一切敌人攻击落在节拍网格（§2）；前摇视觉=音叉蓄光/尘环脉冲，与拍点严格对齐 |
| Satisfying 爽快 | 命中反馈七层同步（§9 hitstop+§10 震镜+VFX+SFX+手柄震动，需求 §47） |
| Skill-based 技术 | 弹反/完美格挡/节拍读解为最强解；难度来自模式识别而非血量海绵（需求 §23） |
| **原创身份** | **「音律节拍」战斗特性**（§2）：敌人=乐句，玩家=休止。弹反=让世界停音的叙事机制化 |

基准参考值（Rank 1、无装备）：玩家 HP 120 / 体力 100 / 轻剑 L1 伤害 9。杂兵 TTK 目标 5-9 段轻击；战斗节奏：一次遭遇 ≤60s。

## 1. 通用帧规则

### 1.1 术语

- **Startup 前摇**：输入到命中框激活。前摇期间被打=动作中断（受击反应按 §8 表）。
- **Active 判定窗**：命中框存在。同一次挥击对同一目标默认只命中 1 次（多段武器分段除外）。
- **Recovery 后摇**：命中框关闭到可再次行动。**取消窗**标注于各武器表。
- **命中停顿（Hitstop）**：见 §9。本作的落法是**按在挨打的那一方**（那段硬直的倒数被按住），
  出手那一方的招式帧不吃它——理由与实测都在 §9 那张表下面。粒子/震镜/音效一直照常。

### 1.2 全局输入缓冲与取消

| 规则 | 数值 |
|---|---|
| 攻击输入缓冲 | 200ms（连段下一段/派生键入队） |
| 翻滚取消 | 攻击进入 Active 起至 Recovery 结束前 40% 可取消进翻滚 |
| 弹反键取消 | 仅 Recovery 段可取消（高风险高回报连段不允许弹反取消） |
| 锁定转向 | 锁定攻击根位移修正：目标在 ±35° 内自动旋身对齐（解析旋转，非 IK） |
| 硬直中移动输入 | 不响应，但方向键影响翻滚方向预测 |

## 2. 音律节拍系统（Beat Grid）——本作原创战斗身份（需求 §86）

### 2.1 全局节拍时钟（BeatClock）

| 参数 | 规格 |
|---|---|
| 实现 | 单例时钟：`beat = (audioContext.currentTime * BPM / 60) % 1`；BPM/小节长由区域配置；与战斗 BGM 同调（IP §11：探索 C 多利亚等调性绑定） |
| 区域 BPM | 雾语林 84 ／ 破拍营地 84（军鼓）／ 钟坠院 92 ／ 沉唱堂 96 ／ 无耳深窖=**无网格**（仅 60BPM 心跳，万籁领域）／ 未竟厅=恩希尔私有时钟（§15.2） |
| 拍→毫秒 | 84BPM：1 拍=714ms；92BPM：652ms；96BPM：625ms；108BPM（奥斯塔拉）：556ms |
| 量化规则 | **敌人所有攻击的命中帧必须落在拍点或半拍点**（±50ms 容差由调度器吸收）；前摇起始允许任意拍位，但调度器会将前摇起点对齐到拍位，保证视觉脉冲与命中同步可预测 |
| 攻击插槽 | 同小节同拍位最多 1 个敌人发动"命中帧"（防止重叠不可读）；冲突则顺延至下一半拍（队列上限 3，超出改为走位） |
| 玩家侧 | 玩家**不受网格约束**（叙事：休止者=节外之音）。进阶奖励：命中帧落在拍点 ±50ms 内→架势伤害 +1（"踏音加成"，HUD 以极淡涟漪提示） |
| 可读性可视化 | ①节拍=环境尘环脉冲（每拍 1 次）②敌人前摇蓄光亮度沿拍-半拍-拍曲线增长 ③Boss=乐句进度线血条上的重拍刻度（IP §10 UI） |

### 2.2 三大节拍机制（Boss/精英的身份技，详见 §14-§15）

| 机制 | 持有者 | 规则摘要 |
|---|---|---|
| **节拍空隙** | 切分「幽灵八 Phantome」 | 只在拍间空隙（"and"位，即半拍）移动与显形；拍点上定身+半透明（不可被击中）。玩家以"拍点闪避"或投掷音色晶制造伪拍点逼其实体化 |
| **3/4 拍弹反窗** | 悬钟骑士·奥斯塔拉 | 全部打击命中帧固定落在每小节第 1 拍（重拍）。重拍弹反窗口扩大为 117ms（7f）；小节线可预测→弹反=读三拍waltz 而非反应力 |
| **夺拍 Steal-the-Beat** | 无拍长·恩希尔 P2 | 他吞掉全局时钟：玩家体力回复改挂他的拍（-25%）、闪避冷却漂移 ±60ms；玩家在其"换气拍"完成弹反=夺回节拍 8s（期间 P2 减益关闭+过载+2） |

### 3.1 家族定价红线（KI-039 裁决，2026-09-24）

**「第一记轻击的伤害 ÷ 它的整段周期」在武器家族之间极差不超过 1.25×**——也就是玩家反复按同一键能拿到的持续输出。
当前锚点：调律剑 9/30=0.300、引针枪 12/37=0.324、强音大剑 21/60=0.350。

理由：**"更重的一击"不能顺带把"更快杀完同一只敌人"也赢走**，否则选武器不是选玩法，是选 DPS 表。
重击的回报必须住在**架势值（22 对 5）、体力（18 对 8）、噪声（§14 听觉半径 ×1.5）、击倒/震裂层数**这些维度里；
轻击的回报住在**出手频率、体力续航、安静、距离（3.2m 突刺）**。

守它的是两道闸：`tests/unit/movesets.test.ts` 直接读帧表算极差（新武器入表当场响），
`tests/flow/gate5.test.ts` G5② 真跑同一只驼鼓量通关节奏（裁决后 673 对 772 tick = 0.87）。
**裁决前是 1.62×**（枪 L1 只有 8 伤）⇒ 站桩对照 613 对 1221 tick，两倍的通关时间差；
下表 §4.2/§4.3 轻击链的伤害列已按本条重锚（大剑 24→21/38→34，枪 8→12/10→13/11→15/17→20），
其余格子（体力/架势/帧数/H 与蓄力）不动——那几维才是重量该拿回报的地方。

**第二条腿：同一把尺子换到高甲目标（悬钟骑士，正面 60°/×0.6 钟甲）。**
0.75–1.35 的容忍带**只对无甲目标成立**——甲是设计好的"重量回收位"，正面减伤让持盾/带甲怪天然更吃重击，
所以那条腿单独量、单独设带：`brawl()` 打不死的高甲量具跑 1600 tick，实测力 0.391 对律 0.279 伤/tick，
**比值 1.40，落在 [1, 2]**；带下界是"重武器不能反而更慢"，带上界是"甲不能把轻武器压成废铁"。
真正的差别住在碎甲时刻：**力在 680 tick 碎甲（蓄力一记带 3 层震裂），律全程碎不了甲**（蓄力只带 2 层默认值）
⇒ 碎甲之后减伤永久失效，重量的回报被机制放大而不是被数值抹平。
闸的证伪：把枪的蓄力也写成 5 层震裂，断言「律碎甲晚于力」当场红（「律碎甲于 88，不比力（680）更晚 ⇒ 甲白叠了」），
说明这条腿守的是机制而不是又一次 DPS 表。

  并且**不吃过载、不起冷却**（被拒的按键不该有代价）。平A/翻滚/弹反不受影响——封的是战技。
  仍然**故意没有** `statuses.mute.skillLockTicks` 这个字段：封锁时长就是"这口闷音还剩几 tick"，
  再写一个 4s 是把同一件事记成两处（第二个常数），而真正给时长的永远是施加方
  （`statusOnHit.ticks` / 和弦爆自己的 `muteTicks` 180/210/240 = 3/3.5/4s）。KI-033 就此撤账。
- **§11 的「每 1 层过载：战技伤害 +4%」和 progression §2.1 的「音色 → 乐章战技伤害 +1.5%」在 5-C2 有了真消费口**：
  `movements.json` 的 `damage.perOverdriveLayer: 0.04` 与 `damage.scaling.ton: 1.5`。两句诚实的口径：
  ① 乘的是**扣掉这一式成本之后**剩余的层数（先付 2~3 层再吃加成，不存在"用掉的那几层还算伤害"）；
  ② 战技走的是 §12 同一个 `resolveDamage`，但**不吃武器强化倍率、不吃武器自身的 scaling/poiseMul**
  ——战技是"你嗓子里的东西"，不是"你手里那把剑的多打一下"（flow 测试用同种子把它钉成精确等式）。
- **和弦爆的 `multi: 8` 是"最多 8 个不同受害者"，不是"打 8 下"**：一次挥击内同一目标只结一遍
  （`markActionHit` + `hitIds` 记账），环外那只一个子儿都不掉。
- **震裂的「对装甲/晶体 ×2」不在状态表里**：那是目标的材质属性，写在 `EnemyData.fissureMul`
  （嘈壳）与 `BossPhase.shell.fissureMul`（壳期奥斯塔拉），由 `Enemy.fissureEffectMul` 合成。
- **回响的挂点由招式自己声明**（`frames.echoOnHit`）：三把近战武器的重击 `h` 有它，敌人招式没有
  ⇒ 回声影是玩家的身份机制，不是双方共用的一条结算。表里"最多 2 影"这道性能锁在真实帧数据下
  打不到（最快重击循环 67 tick < 存活 90 tick），见 KI-032。
- **施加时长归施加方**（`statusOnHit.ticks` / `projectile.muteOnHit`，单位是 tick 不是秒）；
  状态表只回答"挂着的时候值多少"。
- 五态的 `desc` 就是 §19 要求的世界观 tooltip，由 `StatusGlossary` 在"本局第一次见到"时播一次。

## 12. 伤害公式（全系统统一入口 `CombatResolver.resolve()`）

```text
final = base × wScale(attr) × combo × onBeatBonus × rand(0.95,1.05) × (1 - DR)
DR = DEF / (DEF + 120)，上限 55%（远程 DR ×0.6 计算后再取）
暴击 = ×1.35 + 泛音 Overtone 每 10 点 +2%；背刺/处决走 §5.4 固定比例不吃暴击
```

- `wScale` 各武器属性缩放行文见 progression.md §3（力量系/敏捷系/音色系三类标尺）。
- 真伤（处决/碎裂/**战技起手式的追加真伤**）不吃 DR；架势伤害独立通道。
- 友军伤害：关闭（营地多解中敌阵营内部误伤开启——针喉塔位可被诱导误射，潜行解彩蛋）。

## 13. 敌人 AI 状态机全表（需求 §20，11 态）

### 13.0 感知模型（所有敌人共用，实现为解析几何，无射线开销预算：感知 tick 10Hz 轮转）

| 通道 | 规格 | 备注 |
|---|---|---|
| 视觉 Vision | 视锥（距离 18-30m、角 100°）+ 高度遮挡检查（水平射线 3 采样点） | 潜行只在"未被视锥触及"时安全 |
| 震感 Vibration | 半径 4-10m 内移动/落地/疾跑触发（静步半径 12m→4m，见 gameplay.md §3.1） | 静止=对震感隐形（嘈壳等无视觉敌的核心解） |
| 听觉 Sound | 全局事件总线：攻击/弓弦/破坏/弹反冲击按噪音半径广播 | 玩家是聋者≠敌人是聋子；无鸣例外（噪音 0） |
| Alertness 0-100 | 视觉 +34/s（锁定玩家）、震感瞬 +40、噪音按强度；≥60→Alert，≥100→Combat；衰减 -20/s；被弹反/完美格挡目击者 +100（瞬间报警） |

- **弹反冲击这一路（KI-048，2026-09-24 起）**：上面那行「听觉 Sound」列了四条通道，现在成了**三条半**——攻击（KI-016）、弓弦（弹道发射）、**弹反/完美格挡那一记金属相交**（本条）都已接进 `sound.source`，只剩「破坏」还悬着（本仓库没有"可破坏场景物"这一类实体，见 KI-023）。三个要点：
  - **它是表值走同一条标尺，不是一条新通道**：基数在 `player.json`（`parry.impactLoudness = 0.85`、`guard.impactLoudness = 0.5`），出口在 `ThirdPersonController.weaponImpactNoise()`，再乘武器 `noiseMul` 与词缀 `rpg.noiseMul`——所以无鸣/静默一系的角色**防御也是安静的**（§12「零噪音」那句对防御同样成立）。弹反 0.85 排在驼鼓踏地 0.8 之上是有意的：这一记钟响是玩家能弄出的最响的动静之一。
  - **0.85 与 0.5 之差正好跨过幽灵八的伪拍点门槛 0.6** ⇒ 弹反会把她从拍隙里拽出来，完美格挡不会。而这条**不是常开开关**：实机读数里玩家带着 0.733 的静默词缀与引针枪（0.9），弹反那一声是 0.5607 ⇒ 同一个动作在那个角色身上惊不动她。乘法结构白送的差别，但必须写下来，否则下一个人会把它当恒等式。
  - **「目击者 +100」判的是看见，不是听见**：走 `Enemy.sawImpact()`，视锥沿用 `sense()` 那套数（`ai.vision.range / fovDeg`）。之所以挂在视觉上而不是再加一条听觉——除嘈壳外所有敌人的 `vision.range` 都比 `hearing.range` 长（针喉 30 对 20），挂在听觉上就永远测不出这条规则是否真的多给了什么。附带两个后果：**无眼的万籁**（`vision.range = 0`）不吃目击报警，她那条路一直是听觉；已经在交战/追击的同伴不重置状态，只把最后已知位置挪到冲击点。

### 13.2 难度纪律（需求 §23）

- 每种敌人至少 1 个**模式级弱点**（非数值弱点）：槽位可预测性、呼吸拍、广播可打断、节拍显形窗。

## 14. 七类敌人行为规格（IP §5）

### 14.3 驼鼓 Tympanus（Heavy·背驮战鼓巨躯）

- **弱点**：前摇 700ms 极显（背鼓起光随拍点涨亮）；踏地波可侧步穿越（r 判定为圆环：贴脚不伤）；**对鼓面 4 次震裂→鼓崩**：全营节拍同步紊乱（据点战里=巡逻表失效）；弹反其横扫→后颈振源核开 3s。

### 14.4 针喉 Skewer（Ranged·弦指狙击）
- HP 55 / Poise 22 / 速 2.4m/s；射程 26m；弹速 18m/s（可见赤线 telegraph 0.8s，**线终点=落点**）。
- 攻击：①单发｜拍 1｜14 伤；②三叠箭（拍 1/1.5/2）每发 10；③近身拨弦（击退 R3）。
- 行为：距离带 14-26m，永远背退拉近；被贴至 <6m  Retreat 上塔。
- **弱点**：拉弦声=最强听觉信号（聋者玩家看弦光涟漪）；三叠箭第 2 拍为假动作（延迟 0.25 拍），骗翻滚后硬直 0.6s；塔位可被弹反（其箭反射回杀）。

### 14.5 幽灵八 Phantome（Assassin·切分猎手，节拍空隙机制）
- HP 80 / Poise 24 / 速 4.2m/s（仅半拍窗内位移）。
- 机制：`beatPhase` 驱动：拍点 ±208ms 外=实体（可打、可被看见）；拍点上=半透明定身（攻击穿过、无受击）。其攻击命中帧永远在"and"（半拍）位——与全场敌人（拍/重拍）反相。
- 攻击：①背割 S400/A83/R300｜半拍｜22 伤+挂闷音；②切分连踏（2 段半拍）各 12。
- **玩家解法**（教学三板斧）：a) 在它的半拍窗对拼（高手向）；b) 拍点闪避其前摇→其显形 1s 定身破绽；c) 投掷音色晶=伪拍点声源，令其节拍错乱显形 3s。**弱点=它改写全场拍感，玩家学会"用反相打反相"**。
- **声场口径（KI-016，2026-09-24 起）**：伪拍点声源的门槛是 `fakeBeatLoudness = 0.6`，而**场上任何一声都算**——包括敌人自己出的。此前"驼鼓踏地会顺手把它震出来"只是设计上的期望（敌人近战不发声），现在是真的：敌人招式在**刀刃接触那一帧**（`activeStart`）报一声，响度取自招式表 `frames.loudness ÷ 10`（踏地 8 ⇒ 0.8 够响，嘈壳撕咬 2 ⇒ 0.2 惊不动它）；玩家招式仍在**起手帧**报（蓄力长的招式因此提前约 0.4s 报信，这是有意的读招余量）。两个时机口径不同，但共用同一条标尺与同一个事件。

### 14.6 叠唱 Refrein（Support·定调增幅母）
- HP 65 / Poise 30 / 速 2.0m/s；藏于阵后 18m。
- 机制：存活期间周围 12m 喧堕者：攻速 +15%、体力消耗 -20%、伤害 +10%（"定调"，其吟唱=可见五线光栅罩住同伴）。
- 攻击：①噪音弹（直线 18m）S600/A—/R400｜拍 1｜10 伤+闷音 2s。
- **弱点**：本身不近身、不逃跑（最软的靶=最优解的考点）；**击杀它→全场敌人失衡**：所有增附体 -1s 硬直+Alertness 归零（"走调时刻"，奖励正确集火顺序）。

### 14.7 悬钟骑士（野外精英，Boss 剪影的下位版）
- HP 320 / Poise 80 / 速 2.6m/s；披小钟甲（背驮一口礼钟）。
- 攻击：①钟锤二连 S450/A120/R300；S350/A120/R350｜拍 1/2｜22/24；②荡钟横扫（弧线 r=3m）S600/A200/R450｜拍 1｜30+R3；③钟鸣警戒（CallAlly 广播 25m，1.2s 可打断）。
- 机制：钟甲=正面 60° 减伤 40%；震裂满层碎裂其甲（清一次减伤）；每 4 小节"敲钟自鸣"回 15 HP（必须打断的软计时器）。
- **弱点**：荡钟横扫后摇 450ms+背身 1 小节空门→背刺触发器；弹反钟锤二连第二段→钟体共振眩晕 2s。

### 15.3 隐藏 Boss：万籁 The Myriad（无耳深窖最深处）

- HP 380（战长 4-6 min）；山丘大无眼耳兽，踞"音刺"（世界噪音汇聚点）。**无拍点机制**（§2.1：深窖=无网格领域——全作唯一敌人不在节拍上，反差即身份）。
- **声音狩猎规则**：玩家任何 `noiseRadius>0` 行为（攻击默认 3m、格挡受击 5m、弹反 8m）都会使其锁定该点位并猛攻（瞬移咬合 S300/A200/R400｜36 伤）。它视觉=0，听觉锥 360°/40m。
- 解法循环：投掷音色晶到 A 点→其转向 A→玩家在 B 输出（武器：无鸣=零噪音，正解装备教学）；音刺在场=环境干扰器，击碎音刺（重击 4 次）→其短暂聋乱 6s（破势窗口）。
- 它也会"听心跳"：玩家静止 3s 后 Alertness 缓慢降（潜行回血机制）。
- 奖励：独特武器「无鸣」+ 初句圣所地图刻痕（T5 链）+ 战技 IV 乐谱。
- 失败设计验证：全程零强制反应窗；难度纯来自信息管理与资源博弈（音刺位置记谱）。

| 项 | 规格 |

### 16.1 入场演出与胜利序列的实现口径（Phase 5-C2b 已落）

- **数据挂在 Boss 自己身上**（`enemies.json > boss.intro / boss.victory`），不是脚本表：表里写的是"几拍"和"哪几个音"，运行时按**她自己的拍速**换算成 tick。同一份 `beats: 3` 在奥斯塔拉的 3/4@108 下是 100 tick，在恩希尔的 4/4@92 下是 117 tick——差别是设计要的，不是四舍五入的。门禁（`validate:data`）现在要求**每个 Boss 两格齐全**，缺哪一格直接报错，所以"Boss 均带"是机器钉的而不是靠自觉。
- **演出的载体是硬直窗口，不是过场**：那几拍里她只转身（`faceSlow`），不出手、不挪步、不排读条，但**照吃伤害**。这是刻意的惯例（玩家读到"照面=白送的开局"），不是漏洞；万籁的入场故意不带 `sfx`——她的登场是"没有声音"（§15.3 的读相）。
- **胜利序列 = 一次真 hitStop + 一次真掐音乐**：`victory.holdTicks`（表里 30 = 0.5s）走 `GameTime.hitStop`（全作唯一"世界屏息"原语，见下条 ENV-001 口径），同时广播 `audio.music.encounter { start:false, cut:true }`。`cut` 是新语义：**立刻静音**，而不是脱战那条 4s 淡出——淡出听不出"停"。氛围底噪（drone）不断，符合 IP §6"世界屏息"而不是"游戏结束"。
- **ENV-001 的替换件（不得当成已实现）**：需求 §16 那句"音乐停=世界屏息"在完整引擎里是一台电影机（时间轴/遮罩/运镜）。本项目只有 WebAudio + Three.js，所以落成了 **hitStop（世界真的慢到 5%）+ 战斗层瞬时静音 + Boss 级播报**三件实打实的东西；剪影特写、镜头轨道、逐帧动画待 Phase 7 表现层。转阶段的"全频低通 0.8s"（§10）仍属 Phase 8 混音，见 KI-021。
- **播报排在屏息之后**：收尾那行字（"奥斯塔拉止息 · 振源核落在钟影里"）在 `holdTicks` 走完才落——安静里不落字。它按 `time.realSeconds` 排队，因为逻辑 tick 在 hitStop 期间照常推进。
- **一次性的那一面**：演"第一次照面"（`introPlayed`），脱战再回来不重演，否则白送窗口可以刷。振源核走 `loot.firstKill`（同一份数据第二次打死不再掉），见 §9.1/§9.3。
- 回归：`tests/flow/bossshow.test.ts`（拍长换算、整窗零出手、只演一次、`cut` 恰一条、屏息未完不落字）；实机 5199：进战当 tick 起 `introTicksLeft=100`、第 100 tick 才出第一招 `swordchain1`、击杀帧 `rawScale=0.05` 且 30 tick 后回 1、控制台 0 error。
