## 1. 世界历史与时间线（History & Timeline）

### 1.0 纪年法
- **AE 黯纪（After the Dimming）**：以「失谐之夜」为 0 年的现行历法。此前年代写作「前 X 年」。
- 王朝史官以「谐历」纪年（和声王朝建国年 = 谐历 1 年 = 黯纪前 900 年）。本文统一用「前 X / X AE」。
- 元音时代与遗响纪元无逐年信史，只有谱律学者按石刻拍号反推的「粗拍纪年」。本表为其学术共识版。

### 1.1 元音时代（The First Tone）——世界是歌声的凝结
| 序 | 事件 | 说明 |
|---|---|---|
| T-0 | **初声（First Utterance）** | 无名之喉（Nameless Throat）开口。山自低音凝出（低音岭纪），河是滑音，光是高音泛音。无时间，只有乐句。 |
| T-1 | **换气纪（The Great Breath）** | 乐句之间存在停顿。后世守休止派认定：这些停顿与神同等古老。 |
| T-2 | **拍石成纹（Lithic Barlines）** | 岩层开始记录节奏——最早的「刻痕石板」在此期生成，为世界观中一切律学文献的物理源头。 |
| T-3 | **余韵生兽（Age of Reverb Beasts）** | 未消散的乐句自发生成巨兽**歌兽（Songbeast）**：行走的活混响。今仅存化石。 |
| T-4 | **泛音极光成形（The Aurora Chord）** | 高空凝声带首次亮起，成为世界的光源与节拍器。 |
| T-5 | **断章（The Caesura）** | 神唱至半句，戛然而止。无人知晓是换气、被斩断、还是喉咙本身熄灭。一切历史由此开始。 |

### 1.2 遗响纪元（Age of Remanence）——靠残响存活的世界
| 年（约） | 事件 |
|---|---|
| 断后 0–800 | **褪色长冬**：失去歌声灌注，物质缓慢失去振动。第一次「物体无声无息碎成灰」被称为**初褪（First Fading）**。 |
| 约 900 | **拾响时代**：游猎部族发现敲击特定岩脉可放出封存振动——**音色石（Timbite）**首次被采集。人类从「活在歌里」转为「捡拾歌的尸体」。 |
| 约 1500 | **口传谱律**：最早的季节歌、招鱼歌、葬歌成形——民间发现「唱对节奏的东西褪色更慢」。律学前身。 |
| 约 2100 | **初刻律（First Notation）**：有人在骨谱石上刻下可复现的节拍序列，一块风化的岩架因此重新坚硬。刻律者（Notators）成为最早的知识阶层。 |
| 约 2600 | **大管风琴遗址出土**：谐京所在地掘出不可解释的巨型管风琴状岩-晶复合结构（后世称「神喉遗架」）。围绕它形成聚落。 |
| 约 3000 | **第一批聋者记载**：某部族的「听不见残响的孩子」被记录为「被歌漏掉的人」。歧视与神化的双重原型自此埋下。 |

### 1.3 和声王朝（Concordance）前 900 年 – 前 73 年——律政院文明
| 年 | 事件 |

| 前 860 | **音阶籍（The Scale Register）**：以童年期「辨音试」将全体人口定为音感等级一至七阶，设闻者/聋者两级公民籍。阶级制度化完成。 |

| 前 74 | **三百歌者遴选**：全大陆最优音感者入选仪典合唱队，含十七岁的**莉安**。同年，哑带边缘最后聋者聚落被强制迁空。 |

## 2. 文明与社会结构（Civilization & Society）

### 2.1 音感阶级制度（律政院遗产）
王朝把「能否听见遗响」当作灵魂有无的证据，编成**音阶籍**：
| 等级 | 名称（zh/en） | 职能原型 | 权利 |
|---|---|---|---|
| — | 首席指挥 / 声部领主 | 统治者 | 可令他人「入谱」（征税即征声：每人每年上缴固定时长的歌唱劳役） |
| 一至二阶 | 精闻者 Fine-ear | 律师、铸钟师、仪典官 | 独占高阶律学与共鸣井操作权 |
| 三至四阶 | 常闻者 Common-ear | 工匠、军人、农户 | 普通公民；可购买低纯度音色石 |
| 五至七阶 | 浊闻者 Blunt-ear | 力役、矿徒 | 不得研习律学；子女辨音试重考制 |
| 籍外 | **聋者 Hushed** | 无 | 定聋令后：无谱格、不得置产、不得近水源地、出生戴铃、成年剪铃放逐 |

### 2.2 聋者制度化歧视史（主角设定的世界土壤）
1. **神学根**：官修谱律宣称「人是歌的回声」——听不见残响者即「回声缺失之人」，被联想为断章之夜的凶兆。
2. **法学根**：辨音试（六岁、九岁两次）+ 音阶籍连坐：窝藏聋者者降一阶。
3. **肉体标记**：放逐铃（让聋者在人群中「被听见」，因其本人听不见）→ 剪铃刑（成年时当众剪断铃串，银留在耳上，肉上留疤）。主角左耳的断铃串即此刑遗留。
4. **讽刺反转**：王朝晚期密档（科温手中）显示，校音院早在前 4 世纪就观测到聋者不被残响附着、对喧堕前兆免疫，但公开这一事实会摧毁「音感=灵魂」的统治根基，遂将全部记录封存为**哑档（Sealed Silence Files）**。
5. **现今**：王朝崩了，定聋令没有正式废除，也没有人执行——乡野对聋者从「不祥」半公开地转向「宝贝」：乱世里谁都想知道「听不见」的人到底会不会喧堕。主角是被这种半迷信的期望拽进各派漩涡的。

### 2.3 残存社会（现今 · 息声领）
- **城市国家化**：王权消失后，以镇音装置（圣钟、共鸣井）为核的聚落成为基本政治单位。一个井、一口钟、一支看井人=一座城。
- **休垒社会**：骨腔自治会（市政）+ 灰谱行会驻点（技术）+ 执杖残署租界（法统）+ 静驿暗网（聋者救济）四方并存，是全书派系结构的缩影。
- **经济**：音色石本位。碎响（低品音色石渣）为小额通货；劳役仍以「唱时」计（采石场以歌声换口粮的旧制在乡间残存）。

## 3. 派系（Factions）

> 记法：目标 / 资源 / 与他派关系。全部为现今（73 AE）状态。

### 3.1 执杖残署（The Batonwardens）——律政院残党
- **构成**：旧军律乐队兵团遗孤、谱法司文官、失去封地的低阶声部领主。盘踞谐京外郭与三条官道哨站，在休垒仅保「法统租界」。
- **目标**：重建律政院法统；收回初句圣所石刻；将「续章」重新排上议程——他们不认为仪典失败，只认为**排演不足**。
- **资源**：王朝印玺与户籍档（合法性话术）、成建制鸣炉甲军、军乐指挥链（可整队抗喧堕的低阶合声纪律）。
- **关系**：视灰谱为「把国器改成小费的手艺人」；武力截杀赴带巡礼（「私奔到世界坟场」动摇其劳工税基）；对聋者政策分裂——年轻军官主张招募（免疫者=资产），老文官死守定聋令；与破拍营地有暧昧的「旧部队不流血接触」。

### 3.2 灰谱行会（The Grey Gamut）——调音者行会
- **构成**：游方调音匠、律器匠、修井人、验石师。会徽为一根抹了三道灰线的音叉（「调不准的，先别调别人」）。
- **目标**：让「调律」从国家神术降格为可计价的手艺：订价权、契约权、师徒权。对续章/静默之争官方中立，内部两派皆备。
- **资源**：大陆唯一成体系的律器工艺秘谱（琴马合金、音叉钢）、流动技术垄断——没有灰谱，各地共鸣井三年内锈死。
- **关系**：休垒的实际技术生命线，故自治会事事让三分；受雇于所有派系且互相留底档；与铃姨有铸钟师承宿怨（她拒绝申请会籍：「钟不该被定价」）。

### 3.3 赴带巡礼（The Beltbound）——喧堕朝圣团
- **构成**：褪色病晚期者、失去全部「声音记忆」的留声筒持有者、自愿半喧堕的狂徒。无领导，只有路线：向哑带，一直走。
- **目标**：信仰「寂静不是死，是回到歌被唱出之前」。他们不修复、不抵抗，走入带内成为世界地图上的移动坟标；半喧堕者相信被走调之音改写是「被神先摸了一下」。
- **资源**：人数；对喧堕异乎寻常的非攻击共处经验（巡礼队列穿过敌区时常不被袭击——原因未知，谜 M6 关联）；从带缘捡回的「哑件」（不再振动的异常物）黑市。
- **关系**：被执杖截杀、被灰谱回避；休垒民间又怕又敬；断弦的营地对落单巡礼留一条活路，这一条命令救过铃姨。

### 3.4 静驿（The Cutbell Relay）——聋者地下网络
- **构成**：无固定成员，由炉房、井棚、货栈主构成的暗号网；刻「一道横线穿五竖线」的门槛记号。铃姨是其最大保护伞（执行者赎罪）。
- **目标**：把辨音试将成的聋儿在登记前送出领；为成年聋者找「听不见也能活」的工作（看井、守钟、采砗磲）。
- **资源**：各派商路的贿赂线；聋者本身——唯一能无声穿过回声陷阱与喧堕密集区的人链。
- **关系**：与执杖死敌；灰谱默许（技术垄断者不在乎户籍）；主角开场即静驿登记簿上「73 年失联名单」的第一行。

### 3.5 骨腔自治会（The Skep Council）——休垒本地政权
- **构成**：歌兽骸腔首批定居者的家族议会，七席，席次按「守井年资」而非血统。
- **目标**：让休垒比周围世界活得久。不关心大陆法统，只关心井水位与四钟音准。
- **资源**：四镇钟维护权、共鸣井网、骨腔地利（全城声学结构天然偏听偏防）。
- **关系**：各派系在休垒都租得下房间、都买得到安静；正因中立，成为终局抉择的舞台。

### 3.6 掘响遗民（The Delver Remnants）——无耳深窖矿工鬼户
- **构成**：31 AE 封坑后拒不迁出的矿工家族与其后人，穴居半职业化。
- **目标**：在「越来越安静」的深层维持采掘；他们不挖矿石，挖「声音的化石」——老遗响矿脉死亡前留下的振纹层。
- **资源**：唯一敢在深窖活动的人事地图；以物易物的哑铃贸易（摇动不响的铃＝深窖特产，被巡礼视为圣物）。
- **关系**：给科温供解剖样本；向灰谱换修井；对万籁的传闻讳莫如深，只说「井底不要合唱」。

## 4. 信仰与仪式（Faith & Rites）

> 全部原创。信仰对象不是神格化的存在，而是对**同一段历史事实——「神唱到一半停了」**的三种回应。禁绝一切现实宗教符号；礼仪器物只有：钟、音叉、拍板、留声筒、谱线纹。

### 4.1 全章派（The Consummators）——完成派
- **教义**：断章是伤口，世界的义务是把半句**唱完**；唱完即永生。恩希尔是殉道的初祭者，失败只因声部不足——「还缺一首歌的最后一块，也许只需要一个人」。
- **仪式**：**补谱夜**（每季末，信众对谱线石齐唱未完成的乐句，直到一人嗓子哑掉为止，哑被视为「神收的税」）；入教礼「入声部」（认领合唱队三百除名歌者之一的名字，终身以此名应答）。
- **组织现状**：与执杖残署高度重叠，是其后盾神学；极端支派在深窖边缘私筑「分坛」——沉唱堂即最大废弃分坛。

### 4.2 守休止派（The Fermata Watch）——静默派
- **教义**：断章即神谕。换气与乐句同等神圣：**停顿不该被填满**。世界的救赎不是唱完，而是学会像休止符那样正确地「在而不响」。
- **仪式**：**静默餐**（一席人共食而全程无振动——无声咀嚼被视为最高祷文）；丧仪「送拍」（在遗体旁敲一音，任其衰减至自然消失，不追加任何声音）；守者终身带**拍板戒**，戒面无刻。
- **组织现状**：无教会，只有 individually 挂单「巡静者」；民间镇钟的敲法（只敲一、三、五，留双拍空）即其礼法遗存。主角作为聋者被此派天然视为「活的圣礼」——他们最敬重也最不敢碰他。

### 4.3 续写派（The Undercomposers）——续作派
- **教义**：半句就是邀请。神没唱完，凡人不必补原谱，可以**接着写自己的下一句**——文明即续作。乐句有权不一致，异调不等于罪。
- **仪式**：**斗谱会**（两谱人对写、互相接句，判「谁的下一句让世界多活一秒」）；成人礼「自己的小节」（六岁孩童被允许在骨谱上刻一小节，此后每十年可修订一次）。
- **组织现状**：散在城镇，被全章派斥为涂改神稿、被静默派斥为聒噪——却实际垄断了刻痕石板的释读业。科温被灰谱私下归入此派，他自认是「档案员，不是信徒」。

### 4.4 民俗层（跨派通行）
- **朝钟暮井**：晨起听所属聚落镇钟定音，入暮向共鸣井口低声说一句话「存底」。谎言禁忌：没人会在井前立誓（井会把声音存给能打开它的人）。
- **三响礼**：问好用指节敲三下（一拍起、一拍应、一拍留空）。对聋者行此礼被视为失礼——于是休垒人发明了给主角的「二响加一望」：敲两下，然后让他看见你笑了。
- **绝响罐（Lastnote Jar）**：临终者对罐中说话，封蜡，葬时放入骨腔裂缝。休垒地下据说存着建城以来所有「最后的声音」——拾荒者最隐秘、最被严惩的罪名是开罐。

## 5. 地理志 · 息声领（Gazetteer of Restreach）

> 区域层级结构见 IP_SEED §3。每区条目：地貌 / 生态 / 居民 / 遗响浓度 / 环境叙事锚点 / 光照色板（直接引用 IP_SEED §10，不得偏离）。
> **遗响浓度分级（拍级，Bar Grade）**：1 拍=死寂（律学无效），5 拍=丰鸣（物质稳定、回声叠活）。

### 5.1 休垒 Resthold（Main Hub）
- **地貌**：一只史诗期歌兽的完整骸腔，肋骨为梁、颅骨为穹。城市沿**肋市**（集贸）、**椎脊道**（主干道）、**骨髓井**（中央共鸣井）、**颅庭**（穹顶下议事场）四层环形生长。
- **生态**：无野生群落；檐下养**苔蜥**（食声垢，天然清音工），井温恒定使骨白墙皮终年微震。
- **居民**：约两千户；四方派系共存样板；聋者在此第一次「只是街坊」。
- **遗响浓度**：4 拍（骨腔把井的余波匀给全城——世界最接近「活着」的地方）。
- **环境叙事锚点**：① 颅庭穹顶刻着建城名单，名字数随主线减少（世界末日倒计时写进城政）；② 肋市某摊位卖「会唱摇篮曲的石头」——是伪造音色石诈骗，但诈骗者真以为有效；③ 骨髓井井壁嵌满绝响罐残片（合法砌墙材料），贴耳能听见一整面墙的临终耳语。
- **光照色板**：暖琥珀+骨白+炉火橙（IP_SEED §10）。

### 5.2 雾语林 Whisperwode（Forest · 初级区）
- **地貌**：骨白色石灰岩基座上覆针阔混交林，谷雾常留三日。林内水系皆浅，河床铺满**语苔（Lodemoss）**——吸声、存声、受潮缓释的苔类。
- **生态**：**弦蛾**成群啃食振动（雾中银点=消音生物）；**灰鹿**无弦骨、以耳代目；枯立木因遗响枯竭而「站着褪色」。
- **居民**：拾音人（用留声筒采语苔旧声卖与盐歌一类歌贩的个体户）；迁坟后的林中无人村。
- **遗响浓度**：3 拍，局部陷阱点骤降至 1 拍（**回声陷阱**：树冠构成的天然共鸣腔，诱入侵者出声后「重播」其声诱敌）。
- **环境叙事锚点**：① 一丛语苔百年循环播放一支童谣的**前两句**——第三句的位置只有风声（全游戏反复出现的听觉母题）；② 林中哨站残骸里，执杖哨兵尸体保持围坐对弈姿势，棋盘上刻的不是格子是谱线；③ 一棵树腹录着一整段争吵，争吵者口音是谐京腔——他们到底没回来，但吵架被留下了。
- **光照色板**：灰绿+雾蓝+录放音的金色浮尘（IP_SEED §10）。

### 5.3 钟坠院 Fellcarillon（Ruins · 垂直解谜区）
- **地貌**：断崖扇形坡上散布失谐之夜坠出的九座镇音巨钟，坠落姿态各异：半埋、横断、悬于岩架。钟腔即地宫，院内崖层栈道连通。
- **生态**：钟壁凝声霜常驻；**噪壳**以钟体碎晶为壳，形成「会走的小钟」奇观。
- **居民**：无常住；巡礼中继窟（崖脚，供朝圣者最后一夜留宿，墙上写满「带里有什么」的回答）。
- **遗响浓度**：3→1 拍梯度——越靠近最大坠落体**首坠钟（The First Fall）**越「死沉」，钟内腔是领内唯一可以「听见安静」的地方。
- **环境叙事锚点**：① 三号钟内壁有钟铸工的家书铸进钟壁（失误即铭文：他敲错的一拍是求救信号「我这边先哑了」）；② 九钟坠落方向不指向远方而指向**西**——像被谐京**拽**出去的（谜 M7 锚点）；③ 一钟半开口里塞着完整军队队列的甲胄，甲内无骨，甲外摆满朝向钟口的朝圣垫。
- **光照色板**：青铜锈+落日渐层（IP_SEED §10）。

### 5.4 无耳深窖 Earless Deeps（Underground · 高危暗区）
- **地貌**：旧音色石矿坑群，螺旋竖井向下。以**听阈线（Hearing Floor）**为界：线上尚有矿道回响，线下任何声源在离开喉咙半尺内死掉。最深处立着一根汇聚世界杂音的**音刺（Noisethorn）**。
- **生态**：不发声器官演化的洞穴生物；掘响遗民的穴居家族带；越深喧堕者越少——直到完全没有（**安静本身就是捕食者**：万籁吞声域内一切振源无法成形）。
- **居民**：遗民鬼户 200 余口，以哑铃、手影、骨刻交易；「井底不要合唱」是家训。
- **遗响浓度**：2→0 拍。全领唯一存在 0 拍永久域的区域。
- **环境叙事锚点**：① 一条矿道侧壁上所有矿工刻痕在同一高度集体终止（那年他们「挖到了不响的东西」）；② 封存井里传出过一次敲击，节奏是辨音试的点名拍——官方解释：回声；遗民解释：别接；③ 音刺周围地面磨出环形凹槽，像有巨大软体围绕它转了几十年。
- **光照色板**：近黑+病白矿光（低饱和恐怖）（IP_SEED §10）。

### 5.5 破拍营地 Brokenbar Camp（Enemy Camp · 石桥枢纽）
- **地貌**：跨拍桥（领内唯一可通辎重的石桥）两端台地的要塞化营盘，拒马按五线谱位布列。
- **生态**：无自然生态；尸骸因半喧堕不腐不褪，「站着的尸体」维持卫生假象。
- **居民**：旧律政院乐队兵团 200 余，17 AE 哗变后成编制地喧堕化：仍是队列、仍是巡逻、仍按生前军乐节拍行动。断弦是唯一保有指挥权的活人。
- **遗响浓度**：2 拍（军乐纪律人为维持的稳态——营内比野外更「秩序」，这是恐怖感来源）。
- **环境叙事锚点**：① 巡逻换岗准点到分钟，尸体卫兵按名册应卯（应卯声从喉内振源核发出）；② 营中央舞台每晚仍有一次「军乐晚奏」，听众席位上摆着哗变夜之前最后一次慰问演出的节目单；③ 桥下刻满逃亡者的计数正字，最后一个正字差一笔。
- **光照色板**：铁灰+血红节拍照明（IP_SEED §10）。

### 5.6 沉唱堂 Drowned Choir（Mini Dungeon · 雾语林深地下）
- **地貌**：天然溶腔改建的续章仪典分坛，倒悬唱席吊于穹顶，中央下沉式合唱池常年积「凝声之水」（饱和遗响液，声落水上不起波）。
- **生态**：凝水滋生**鸣蛭**（吸食喉部振动的环节动物，分坛废弃后野化）。
- **居民**：无。奥斯塔拉悬吊于穹顶，73 年「值守」一座没有唱诗班的堂。
- **遗响浓度**：4 拍——与危险正相关：分坛是全领最丰鸣点，正因当年这里是把「更多声部」接进仪典的接口。
- **环境叙事锚点**：① 倒悬唱席上乐谱全是空页，只有每一页第 4 小节印有密集音符——他们提前抄好了「半句之后的部分」（谁写的？）；② 合唱池底沉着三百只入声部礼的铭牌，主角在池边可摸到刻名（莉安的位置留白——谜 M2）；③ 一处哨位上骑士甲保持向上仰望吊钟的姿势锈死，甲内塞满他生前攒的止疼蜡丸。
- **光照色板**：借用钟坠院青铜+深窖病白之间的「水下铜绿」过渡段（IP_SEED §10 派生色）。

### 5.7 未竟厅 The Unfinished Hall（Main Boss Arena · 大管风琴废墟最高层）
- **地貌**：神喉遗架顶端露天塔层，管阵如林高耸入极光带下缘；恩希尔的王座=整座管风琴。地面谱线状裂纹会随其乐句亮起。
- **生态**：无；极光穿管而下的光尘在此常驻（世界唯一「看得见声音」到这种程度的地方）。
- **居民**：恩希尔与其体内三百余「声部」。
- **遗响浓度**：5 拍（过量）——物质在持续过度振动中缓慢**烧蚀**：台阶边缘如蜡泪，越接近王座越「融」。
- **环境叙事锚点**：① 管风琴音栓中有整排被硬拔出的痕迹，孔位空响——73 年间他试过把声部拔出来又插回去；② 厅门内侧刻着仪典排期表，最后一行日期永远停在失谐之夜；③ 从厅顶平台望出去，哑带的裂口在极光下清晰可见——它在厅的正西，和九钟坠落方向一致。
- **光照色板**：管风琴金+失谐紫黑（高对比终局感）（IP_SEED §10）。

### 5.8 初句圣所 The First Phrase（隐藏房 · 深窖最深层之下）
- **地貌**：非人造溶结球腔，壁面为完整无断层的「原振纹」岩——神断章前最后半句以石刻方式自存的唯一副本（也是唯一副本？无人在室外光下核对过，因核对需两人，需两人都听不见）。
- **生态/居民**：无。腔内空气本身有质量感，入腔者报告「像被含在嘴里」。
- **遗响浓度**：悖论值——仪器读数为 0（它不发声），但靠近时所有其他遗响读数**归零重排**。它不是响，是**发声前的那个动作**。
- **环境叙事锚点**：① 石刻半句的收束处不是断裂而是**起笔**——像神随时可能续上（终局道具：主角以聋体「拓谱」，唯一可行抄录法）；② 腔壁有一处刻痕远比全腔新：一个休止符号，笔迹属静驿最高暗号层级，落款空缺。
- **光照色板**：无光源。唯一照明是进入者自身装备的音色石「向它倾斜发光」（晶体对未唱之音的趋性）——光照即引导，玩家行为即叙事。

### 5.9 领外速写（远期扩展用，禁止在 VS 内直写细节）
**哑带 Hushbelt**（横贯大陆中部的声音死域，年推进约一里）；**谐京 Chordana**（废都，大管风琴基座，失谐漏源）；**白鸣原 Whitenoise March**（西部长满嘶声灰草的草原，恒底噪反常稳定，牧羊人以「无调口哨」驱群）；**高喉山地（Uvula Heights）**（北方，据传有比初殷钟更早的钟，无人验证）。

## 6. 律学体系（Tunurgy）完整规则

> 本节为玩法系统（战斗/状态/经济/谜题）直接引用的硬规则层。术语以 IP_SEED §2、§13 为准。

### 6.1 术语
- **遗响 Remanence**：万物振动的残余能量，世界存续的通用代谢物。
- **音色石 Timbite**：遗响的自然凝结体。半透琥珀晶体，内凝波纹；受敲击放出被封存的「最后一声」。货币、能源、锻造材、弹药四合一。
- **本音 True-tone**：每样物质固有的固有频率（律学界的灵魂等价物）。
- **调律 Tuning**：以律具（音叉/弦器/喉咏/拍板）拨回或放大他物的本音。三大正当应用：**校准**（愈合/加固）、**放大至碎裂**（破坏）、**共振驱动**（机关）。
- **喧堕 Cacophony**：失谐残响寄生在有生命的「腔体」上，以宿主振动为食，体内凝出可见**振源核 Discord Core**。
- **禁律·合声 Forbidden Chord**：将多个灵魂强行叠合为「声部」增幅。已随恩希尔成为绝术（理论上——见 §10 谜 M5）。
- **休止 The Rest**：聋者无音感腔体的天赋态；可令失控振动彻底停止。唯一不能「调」的东西，是「不响」本身。

### 6.2 硬规则（HARD RULES，违反者系统层面不可能）
- **R1 守恒律**：调律不创造振动，只搬运与重排。每次施法都在净消耗世界存量遗响——**世界的魔力使用本身是末日倒计时的一部分**（叙事级经济阀门）。
- **R2 腔体律**：残响只能附着于「有音感腔体」之物。闻者可被疗愈也可被喧堕；**石、水、死物不可被喧堕；聋者不可被调律亦不可被喧堕**（主角闪避/防御部分技能成立的法理基础）。
- **R3 本音律**：一切实体可被其本音反向干扰——弹反=以正确频率在正确时点回敬；振源核=喧堕者的「外置本音」，是其力源与其死穴。
- **R4 回声税**：越大的调律效应必然产生越重的回声余像（状态**回响 Echo** 的世界观实现）：重击命中挂回声影，延迟重演。
- **R5 借音染律**：长期接触外来/失谐之音，自身本音被改写（状态**失谐 Corruption**、褪色值），终点为喧堕化或褪色死。无免费增幅。
- **R6 合声禁律**：灵魂可作声部叠合，施术者承受全部声部的「音压」；被叠者意识不灭而不得独奏——恩希尔的存在形态即此律的活证。
- **R7 休止代价**：休止之力每次深度使用，使用者自身存在「变轻」（叙事计量：**轻生度 Fading Weight**；表现为 NPC 记不住他、照片式记忆褪色、骨腔对他的共鸣变浅）。终局抉择的数学基础。
- **R8 晶体律**：音色石封存声的保真度随纯度与敲击工艺而定；碎响渣仅可作燃料；**同一枚石只能放出最后一声一次**（消耗品法理）。
- **R9 哑带律**：带内一切调律失效、带缘外泄即失谐源；0 拍永久域内「安静」可作为实体捕食（万籁生态位成立）。
- **R10 镇音律**：钟与井不是「消灭」失谐，而是把区域本音「钉」在节拍网格上（圣钟/共鸣井=区域稳态器）。钟裂=区域节拍崩=敌人行为失序度上升（铃姨任务线的系统学依据）。

## 7. 科技水平与器物（Acoustic-Crystal Civilization）

> **无蒸汽、无电力**。技术树单一主轴：**对声与晶的控制精度**。基准≈晚期手工业时代＋共鸣机械巴洛克。

- **能源**：共鸣井（抽载地下遗响矿脉的「声波油井」）、鸣炉（以敲晶序列持续放能的工业炉）。
- **照明**：**敲光灯**——轻敲灯芯音色石，光即被点燃的声音（亮度衰减=声音衰减，一盏灯是一声逐渐消失的喊）。
- **传动/建筑**：共振门、共振升降台 **Levanker**、音壁砌法（按谱线角度砌墙可导声至指定房间——贵族的「无声召仆墙」）。
- **记录**：留声筒（lodgment horn，吹入一段声封存，摇放一次即永失）、语苔拓板、刻痕石板（最硬档案）。**文字存在但非唯一记录介质**：文明等级按「可保存声音的时长」衡量。
- **测量**：测音杖（本音探针）、拍规、辨音试套仪（国家机器的最小零件）。
- **军事**：鸣炉甲（以晶振驱动的全覆甲，聋者穿之无人肯卖——它需要被「调」）、拒马谱线阵、军乐指挥链（整队抗失谐的野战纪律）、**定弦钩 Tensionhook**（攀藤/拉近/绊马三用的制式律具化钩索）。
- **民器**：调音桩 Stakerite（营火位=成长点分配的公用地插桩，各村形制即方言）、哑铃（深窖证物级互赠）、绝响罐。
- **技术伦理线**：灰谱行会的「订价权」本质是**知识专利化**；执杖残署手中保留整机级失传工艺（大管风琴谱架）——科技断层本身是剧情资源。

### 8.2 普通野兽（本音正常生态）
- **灰鹿**：无弦骨、耳廓占头三分之二，以耳代目判危；领内猎户主粮，肉无味（其本音缺「鲜」分量）。
- **苔蜥**：食声垢，屋檐清道夫，驯养成本低，休垒家家有。
- **弦蛾**：啖振动的银色小蛾，群过如雾；养蜂人旧法改「养蛾」控林内录音失真的灾害防治业。
- **鸣蛭**：沉唱堂野化种，贴水无声而行，是「安静区」最廉价的活警报器（掘响遗民随身养）。

### 8.3 歌兽与化石（Songbeast）
- 元音时代活混响的凝固体型后代；体型自山丘至城郭级。行为学唯一共识：**全部化石朝向哑带**，前肢姿态如倾听（M5）。
- 骨质含拍状微纹（**骨谱 Bonenotation**），是骨腔穹顶能匀声、辨音试套仪能校准的材料根基；骨矿化后仍响应极光（休垒穹顶在极光强一档时会「合鸣」——世界观时钟的实体报时）。
- 现存争议学科（续写派主导）：歌兽是否即神半句的「听众」——被歌唱出来的、为了继续听而站着死的器官。

## 9. 关键人物小传（Dramatis Personae）

> 条目格式：身份 / 小传 / 动机 / 游戏开场状态 / 秘密或钩子。

- **恩希尔·万籁 Hersil Vaanlay, the Unmeasured（Main Boss）**
  身份：王朝末席首席指挥，今未竟厅的「无拍者」。
  小传：谐京贫音巷出身，以绝对音感捐身部领；一生信奉「唱完就能不死」。仪典失败之夜他做的第一个决定不是逃，而是**把责任叠进自己身体**——三百在场者被他以合声禁律收作声部，73 年不歇地替他续奏。
  动机：表层的救赎（替死者完成）与深层的懦弱（他不敢承认半句本就不可补）同居。
  开场状态：半人半管风琴，再无任何节拍能约束其身（时间不节、眠不节、死不得）。
  钩子：他至今认得莉安的名字，每一句台词里都留出她的那个声部空白。

- **莉安 Lian（主线目标/终局变量）**
  身份：主角之姐，仪典合唱队第一声部。
  小传：前 74 年被遴选时 17 岁，替幼弟（主角）顶过两次辨音试模拟；她是家里唯一「听得见」的人，一生在「替全家回答神」的负罪里。
  动机：失谐之夜她第一个听出「谱面在流血」，未能阻止；此后意识在合声中保持清醒却无法独奏。
  开场状态：恩希尔体内「第一声部」音栓；合声中时间停滞，容貌定格于 26 岁，73 年如一夜（M2 实体）。
  钩子：她是唯一有可能记得「那半句之后世界实际发生了什么」的证人。

- **铃姨 Belltongue（Hub NPC · 铸钟人）**
  身份：休垒唯一能铸镇钟的匠人；前朝谐京钟局都铸。
  小传：0 年前她受律政院令为聋者收容营铸「点名钟」——钟声所到，聋儿不得离场。她以为只是行政设施；流放路上死掉的孩子让她用 73 年去数那口钟敲了多少次。今在休垒隐名修四仪钟（殷/铿/淙/瑝：大铿 Grandclang、长瑝 Everchime、暗淙 Dimwell、初殷 Firstroll 之外的休垒副本钟，原名毁于王朝末年）。
  动机：把每一口修好的钟「还给没被它救过的人」。
  开场状态：左臂残（举锤过度），认出主角耳上断铃时失手摔了模芯。
  钩子：她是静驿最大保护伞；四钟每修一口，一区域天候与敌潮改变；她知道点名钟的原始铭文里藏着一行「非音阶籍」小字。

- **科温书记 Scribe Corvin（灰色学者 NPC）**
  身份：律政院末代档案官，哑档唯一释读者，「喧堕学」奠基人。
  小传：三十七岁编完《声部除名志》，发现三百歌者除名日期全写为同一日——国家机器提前 73 年记下的死亡。他因此转向实证：解剖喧堕者以证明「灵魂在核不在腔」，动摇音阶籍神学。

  开场状态：休垒租界阁楼，悬赏收购振源核，雇主角做「采集人」。
  钩子：为拿振源核活捉平民做转化实验（揭露/包庇双支）；他手里有主角的静驿登记原始页——买来的，但烧掉了。

- **盐歌 Salt-Meg（歌贩 NPC）**
  身份：行走的留声人，莉安旧日合唱队挚友。
  小传：仪典因孕退选（她一生将此称为「我的走音救了我和我女儿」，女儿去向讳言——远期扩展线）；此后以贩卖各地「声音拼图」为生：一枚枚留声筒按序拼出一个人的记忆。
  动机：把莉安「还」给弟弟——用一段一段声音把姐姐重新存在一遍。
  开场状态：沿雾语林—休垒商路巡回，唱摊在肋市。
  钩子：她交付的每段姐姐记忆是主线钥匙；她在/离开直接改变 Hub ambience；她的留声筒里有一段「不该存在的、失谐之夜之后的莉安声音」（M4 锚点）。

- **断弦 Haltrune（营地领袖 NPC）**
  身份：破拍营地叛逃守卫队长，半喧堕义体兵。

- **无面童 Faceless（终局变量 NPC）**
  身份：哑带边缘捡回的失声孩童。

  钩子：祂写下的每一版半句都让附近物质「褪色加速或回稳」二选一——世界之歌下一个容器可能是祂；多结局关键。

- **悬钟骑士·奥斯塔拉 Ostlara, the Hanged Knight（Mini Boss）**
  身份：沉唱堂分坛守阶骑士，与巨钟熔铸者。
  小传：仪典护卫序列末位，负责在分坛敲钟校准接口。失谐之夜钟声没有停下，他与钟、与整座倒悬唱席一起被「挂」进了时间——清醒但节拍停不下来。73 年里他把堂内每页空乐谱按顺序编了号。
  动机：执行一道早已无意义的命令：「钟响之前，不得有人离席」。

- **万籁 The Myriad（隐藏 Boss · 域级现象）**
  身份：失谐之夜所有被吞没声音的「集合耳」；栖于无耳深窖最深处音刺之侧。

  开场状态：蛰伏听刺；以声东击西战之，奖励无鸣 Needlesilence。

## 10. 主要冲突与世界谜团

### 10.1 三层冲突
- **表层（生存冲突）**：褪色倒计时——极光逐年变暗、哑带逐年变宽，聚落依赖的钟与井在坏。玩家每修一口井都在延缓一件注定发生的事；敌潮（喧堕生态扩张）是这一过程的可见端。
- **中层（政治冲突）**：**初句圣所半句石刻**的唯一钥匙是「聋」——只有听不见者能拓谱而不被其烧蚀（R2/R7）。执杖要续、全章派要奏、守休止派要封、灰谱要价、自治会要活、巡礼要送给哑带——主角的身体成为七方争渡的渡口。
- **底层（形上冲突）**：**「唱完」是否等于「结束」**。全章派许诺完成=永生；但守休止派隐藏的前提是——唱完的歌才是**死**歌，歌因半句而仍在被唱。若静默派对，恩希尔与律政院 900 年的国策从根上是灭绝工程；主角的每一次「休止」都在演示答案。终局双结局（救姐姐=毁谱 / 取半句=姐姐成绝响）让玩法选择与底层冲突同题。

### 10.2 世界谜团（不给答案；全部供 item lore / 环境叙事引用）
- **M1 为何而止**：断章是被斩、是换气、还是喉咙本身熄灭？所有学派共享一个无人敢测的前提——神还在不在句中。
- **M2 停摆的第一声部**：莉安在合声中 73 年如一夜；合声内部时间形态无记载可考。科温的哑档里有一条被涂掉的手注：「声部不衰老，声部在**等**」。
- **M3 每一次都不一样的半句**：无面童写出的是「神的原谱」还是「神的候选谱」？若原谱可被改写，世界之歌是否从来就没写完过——它一直是草稿？
- **M4 不应存在的声音**：盐歌手中有一枚筒，封存日期晚于失谐之夜的莉安嗓音。要么留声筒造假（不可能，工艺在铃姨手里），要么那一夜有声音**先于**那夜存在。
- **M5 朝向哑带的兽骨**：全大陆歌兽化石同方向「倾听」；它们站着死。若化石朝向是听，它们听见了什么方向的开始？
- **M6 声音的去向**：哑带吞掉的声音并未归于无——巡礼队列不被攻击、深窖封井的点名拍、万籁的「集合耳」，三者共同暗示：**安静是个容器**，里面装满了会动的东西。
- **M7 坠钟的方向**：九钟坠落与哑带方位一致指向西（谐京），像被首都地下某物**拽回**。而初句圣所的岩腔里，拓谱人会发现石刻的起笔方向朝东。两个方向各指一个「开始」。
- **M8 极光是什么**：官方天文学：遗响蒸腾的可见光谱。守休止派：祂的换气读数。老矿工的口径最准也最没人敢验证：「灯」。
- **M9 同名之罪**：恩希尔家名「万籁 Vaanlay」在谐京方言里是「所有声音的主人」；深窖兽亦被乡民呼为「万籁」。两词同源或同罪，档案在点名钟铭文与骨谱之间——需要两种没人同时具备的知识：能读谱的耳朵，和不被谱听见的耳。
