# CAESURA《止音纪元》 · 新六地域设定册（NEW-LANDS v1 · 2026-11-15）

> 本文件是 **设计稿**（DESIGN ONLY），不入库数据、不落 runtime、不设 KI。它把《止音纪元》的边界向外推一层——
> 七地域之外的「余响新大陆」。玩家敲下《未完之殿》最后一记之后，世界并不结束——它只是安静下来，等待被听见。
> 与 `docs/WORLD-BIBLE.md` / `docs/EPIC-V.md` 同源：所有新 region ID、boss、NPC、钟记、词汇都在这一册落成第一版。
> **永远不写世界外的物质规律**：没有飞行、没有复活、没有神力。六地域的「不可思议」都只从钟与声学里长出来。

## 4 · 新七条主线（增量，不改旧五条）

1. **风钟巡礼** — 风钟海岸的风替每位旅人吹一记，吹响后抵达雨钟谷地前需要把它忘在崖边。
2. **雨钟起诉书** — 雨罪审判者手里的那页纸，是七条沉钟罪责的一部分；集齐才是《风钟审判》的法庭。
3. **石喉记账** — 低音之城的母亲让玩家把自己所有说过的每句话换算成低频数值；每一句都收银。
4. **千门敲门** — 回廊钟每一扇门背后都是同一扇门；只对"你来时打过的那一记"回应。
5. **霜锤验收** — 霜锤钟匠的每一把锤子都严格淬火过；验收条件 = 敲一记后**听到自己回来的声音**。
6. **木钟预言** — 旧钟的主人给玩家一份欠条：敲过的每一下都替玩家记了；哪两记最重要由玩家画押。
7. **六音合奏** — 六种低八度音 ♭E2..♭G2 不按序排方，按「遗忘的顺序」排——只给被沉默过的人才听得见。
